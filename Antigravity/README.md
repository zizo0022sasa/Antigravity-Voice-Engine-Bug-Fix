## 🤝 نظام العمل المزدوج (Dual-Agent Governance)

1. **🤖 Antigravity (المطور والمنفذ المحلي):**
   - مسؤول عن صياغة الخطة الشاملة، وحين صدور الاعتماد النهائي يتولى التنفيذ المحلي، فحص العتاد الحقيقي (Windows 11 / 4K @ 225%)، وتشغيل الاختبارات والرفع إلى GitHub.
   - **ممنوع من تنفيذ أي سطر كود قبل اجتياز بوابة مراجعة الخطة.**
2. **🔎 الوكيل الخارجي (الحكم والمراجع المعماري المستقل — READ-ONLY):**
   - يفحص الخطة والكود بعين ناقدة وفق **المعايير السبعة الحاكمة** أدناه، ويتأكد من عدم وجود أي ثغرة أو تعارض أو نقطة مفتوحة قبل إعطاء إشارة الاعتماد (`APPROVED FOR EXECUTION`).

## 🏛️ المعايير السبعة الحاكمة لمراجعة الخطة (7-Pillar Gate)

كل قرار أو تعديل في [`PLAN.md`](./PLAN.md) يجب أن يجتاز هذه البوابات السبع معاً:
1. **🔒 الحوكمة وعدم كسر المعمارية:** التزام مطلق بـ [`.agents/rules/00-architecture-governance.md`](../.agents/rules/00-architecture-governance.md) (صفر تفريغ خارجي STT/Whisper/API، صفر اتصال بالشبكة، مهمته الوحيدة إلقاء ملف صوتي خام محلياً).
2. **🪶 البساطة وعدم التعقيد (Zero Over-Engineering / KISS):** رفض أي حل معقد أو استعراضي قد يخلق أعطالاً جانبية (مثل رفض تمرير الصوت عبر `stdin pipe` لـ `ffmpeg` لتجنب Deadlocks أنابيب ويندوز تحت `pythonw.exe`).
3. **🔄 الديناميكية والمرونة (100% Dynamic):** صفر مسارات ثابتة، صفر أرقام إصدار بايثون صلبة، وكل سلوك قابل للتخصيص ديناميكياً من `config.json` أو `config.local.json`.
4. **🧱 القابلية للتوسع وسهولة الصيانة (Scalable & Maintainable):** مصدر حقيقة واحد للإعدادات (`config.py`) ومصدر واحد لتعريفات النظام (`win32_api.py`)، وكل ملف كود أقل من `9.5KB`.
5. **🛡️ منع التعارض (Zero Conflict):** عدم التعارض مع `AutoHotkey`، أو اختصارات البرمجة (`Ctrl+F9`, `Shift+F10`), أو `Explorer`, أو نوافذ المسؤول (`UAC/Admin`).
6. **🎯 الحتمية وصفر بنود مفتوحة (Zero Open Ends):** كل ملاحظة في تقرير التدقيق لها قرار حاسم مغلق (`DEC-01`..`DEC-08`) ومهمة مقابلة واضحة.
7. **✅ قابلية الإثبات الآلي (Verifiable CI):** اختبارات وحدة معزولة لا تلمس حافظة أو مايك المطور، وتعمل تلقائياً على GitHub Actions (`windows-latest`).
