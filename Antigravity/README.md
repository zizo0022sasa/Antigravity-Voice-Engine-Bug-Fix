## 🏛️ المعايير السبعة الحاكمة لمراجعة الخطة (7-Pillar Gate)

1. **🔒 الحوكمة وعدم كسر المعمارية:** التزام مطلق بـ [`.agents/rules/00-architecture-governance.md`](../.agents/rules/00-architecture-governance.md) (صفر STT خارجي، صفر اتصال بالشبكة، ومطابقة وثيقة الحوكمة مع `DEC-02` وفق `R9`).
2. **🪶 البساطة وعدم التعقيد (Zero Over-Engineering / KISS):** التماسك المعماري يعلو على عدد البايتات؛ **حُذف سقف الـ 9.5KB المصطنع من اختبارات الكود (`A4`)**، ورُفض `ffmpeg stdin pipe` لمنع Deadlocks أنابيب ويندوز.
3. **🔄 الديناميكية المتزنة (Dynamic Config vs Named Engineering Constants — `R6`):**
   - **إعدادات سلوك المستخدم** (الاختصارات، الوضع، مسار الحفظ، قوائم الحظر/السماح) ديناميكية بالكامل في `config.json` مع دمج عميق (`deep_merge`) لـ `config.local.json` (`R4`).
   - **الثوابت الهندسية الفيزيائية الداخلية** (`WATCHDOG_POLL_SEC = 0.035`, `UI_IDLE_POLL_MS = 50`, `SUCCESS_BADGE_MS = 950`, `HOOK_PROBE_SEC = 2.0`) تبقى **ثوابت مسماة داخل الكود** ولا تُلوِّث ملف إعدادات المستخدم (`R6`).
4. **🧱 القابلية للتوسع وسهولة الصيانة:** مصدر حقيقة واحد للإعدادات (`config.py`) ومصدر واحد لتعريفات النظام (`win32_api.py`).
5. **🛡️ منع التعارض:** إغلاق تعارضات `AutoHotkey`، واختصارات IDE (`Ctrl+F9`, `Shift+F10`), و `explorer.exe`، ونوافذ المسؤول (`UAC/Admin`).
6. **🎯 الحتمية وصفر بنود مفتوحة:** دمج `100%` من البنود الـ 15 (`A1–A5` الإلزامية + `R1–R10` الموصى بها).
7. **✅ الاختبار التوصيفي قبل الهيكلة (`Characterization-First` — `A4`):** كتابة اختبارات الوحدة للمنطق الحرج كأول خطوة (`T-P0-00`) **قبل** أي إعادة هيكلة، مع مصفوفة GitHub Actions CI لبايثون `3.10–3.13` (`R2`).
