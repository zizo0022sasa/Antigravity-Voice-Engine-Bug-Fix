# 🔒 الدستور المعماري الصارم لمشروع Antigravity Voice Engine
> **قاعدة حوكمة سيادية غير قابلة للتغيير نهائياً (Immutable Architectural Boundary)**

## 🚫 الممنوعات القطعية (Zero External Transcription & Zero Network Rule)
1. **ممنوع منعاً باتاً** إضافة أو ربط أي محرك تفريغ صوتي خارجي (سواء Gemini API خارجي، OpenAI Whisper، faster-whisper، بوت تليجرام، سيرفرات سحابية، أو أي تطبيق طرف ثالث لتحويل الصوت إلى نص)، وممنوع أي اتصال بالشبكة نهائياً.
2. **المسؤولية الوحيدة للمشروع (Single Responsibility Principle):**
   - التقاط الصوت محلياً بأقل زمن استجابة (Push-to-Talk / Smart Toggle).
   - ضغط الملف محلياً بصيغة `M4A/AAC` عالية الكفاءة في الخلفية الصامتة بدون سرقة الفوكس (`CREATE_NO_WINDOW`).
   - حفظ الملف بتسمية زمنية قياسية مرتبة (`Voice_YYYY-MM-DD_HH-MM-SS.m4a`) بدون اسم اليوم النصي.
   - وضع ملف الصوت في الحافظة المحلية (`CF_HDROP`) ولصقه في نافذة الشات النشطة للمستخدم (مصمم أساساً لـ **Antigravity IDE**، ويسمح افتراضياً بأي نافذة نشطة غير محظورة مثل المتصفحات مع حظر مستكشف الملفات `explorer.exe` وإتاحة التقييد الحصري الاختياري عبر `allowed_paste_processes` وفق `DEC-02`).
3. أي تعديل مستقبلي يحاول تحويل الأداة إلى أداة Speech-to-Text خارجية يُعد **خرقاً مباشراً للمعمارية والحوكمة** ويُرفض فوراً.
